# Security Policy

> Updated 2026-09-06 by Howard Edwards: aligned supported versions and private disclosure guidance with the current 2.x release.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.x   | :x:                |

## Reporting a Vulnerability

Privately report suspected vulnerabilities through [GitHub Security Advisories](https://github.com/howard-e/sequelize-jest-kit/security/advisories/new). Do not open a public issue for an undisclosed vulnerability.

You can expect to get an update on a reported vulnerability within 7 working days.

## Dependency vulnerabilities

Dependabot and Snyk scan dependencies for known vulnerabilities. Dependency updates are integrated through the `develop` branch.
